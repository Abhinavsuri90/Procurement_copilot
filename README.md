# Procurement Request Copilot

AI copilot that reviews employee software/service purchase requests: it gathers evidence with typed tools, applies a
deterministic policy engine, recommends the next action and hands every decision to a human.

**Run it:** `python start.py` → http://localhost:8000 (works without an API key; see `.env.example`).

Full documentation (architecture, evaluation, ship decision) is being finalised. The starter-pack brief is in
`docs/Assignment_3_Brief.pdf`; starter fixes are in `docs/STARTER_FIXES.md`.
